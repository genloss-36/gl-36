## Transactions

| Limit | Value |
| --- | ---: |
| Largest instruction data | 81 bytes (`init`) |
| Largest account list | 5 accounts (`mint`, `buy`) |
| A `buy` transaction | about 400 bytes of the 1,232-byte limit |

## Throughput

Every instruction writes the collection account. Solana allows 12M compute units per writable account per block, so one collection handles about 4,000 mints or buys per block, or about 30,000 transfers. Different collections never contend with each other.

## Layout version

`version` is byte 1 of the header and is `1` for everything described here. A future layout will use a new version number; the program rejects accounts whose version it doesn't know, and decoders should too.
