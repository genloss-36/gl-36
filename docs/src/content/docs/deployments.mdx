GL-36 runs on Solana **mainnet**.

<Deployments />

Every collection belongs to a project: a mint with its own generator and site, sharing this one program. The list comes from the repository's deployment registry, `deployments/mainnet.json`, which each project's deploy script updates with its own collections. **GENLOSS**, the first project on GL-36, mints at <a href={GENLOSS_URL}>genloss.gl36.org</a>.

## Build

| Property | Value |
| --- | --- |
| Crate | `gl36` 0.1.0 |
| Framework | Pinocchio 0.12, `no_std`, no allocator |
| Target | sBPF v3 |
| Binary | 21,584 bytes |
| Toolchain | Rust 1.89+, Agave CLI 4.x |

The binary is small enough that its own rent — refundable if the program is closed — is about 0.1 SOL at today's rate.

## Measured

A full cycle on a 5,000-token collection and a 3-token collection that sold out, in 15 transactions:

| Step | Compute units |
| --- | ---: |
| `init`, supply 5,000 | 3,253 |
| `mint` × 1 | 2,971 |
| `mint` × 10 | 3,189 |
| `mint` × 3 | 3,064 |
| `list` | 452 |
| `buy` | 2,901 |
| `transfer` | 374 |
| `list` + delist | 863 |
| `reveal`, closes the mint | 457 |
| `withdraw_excess` | 401 |

Minting one token at a price of 0.01 SOL cost the minter 0.010188 SOL in total: the price, the rent for 36 bytes and the network fee. All 15 transactions together paid 0.000075 SOL in network fees.

<Note label="Verifying the program">
  Build <code>program/</code> with <code>cargo build-sbf</code> and compare the hash of <code>target/deploy/gl36.so</code> with the program data on chain, for example with <code>solana-verify</code>.
</Note>
